TalentSync AI – AI-Powered Resume Screening Platform

Problem Statement

Recruiters often receive hundreds of resumes for a single job opening. Traditional Applicant Tracking Systems (ATS) rely heavily on keyword matching, causing many qualified candidates to be overlooked simply because their resumes use different wording. Manual screening is time-consuming, inefficient, and difficult to scale.

Solution

TalentSync AI is an intelligent recruitment platform that uses Natural Language Processing (NLP), Sentence Transformers, and semantic similarity matching to compare resumes with job descriptions. Instead of searching for exact keywords, the platform understands the meaning and context behind candidate profiles, helping recruiters identify the most suitable applicants quickly and accurately.

Key Features

  • 📄 Resume parsing and information extraction
  • 🧠 Semantic similarity matching using Sentence Transformers
  • ⚡ FAISS-powered vector search for fast candidate ranking
  • 📊 Hybrid scoring based on semantic similarity and skill overlap
  • 🔐 Secure JWT authentication system
  • 💾 MongoDB database integration
  • 🚀 Redis caching for faster performance
  • 📈 Detailed candidate insights and ranking dashboard
  • 🎯 Real-time job-resume matching system

Tech Stack

React FastAPI Python MongoDB Redis FAISS Sentence Transformers JWT Tailwind CSS Docker

How It Works

The system converts resumes and job descriptions into high-dimensional vector embeddings using the all-MiniLM-L6-v2 Sentence Transformer model. FAISS is used to efficiently search and compare these vectors. Candidate ranking is generated using a hybrid scoring mechanism:

  • 70% Semantic Similarity Score
  • 30% Skill Matching Score

This approach ensures more accurate candidate recommendations compared to traditional keyword-based ATS systems.

Challenges Faced

One of the major challenges was implementing semantic matching that understands context rather than exact words. Building an efficient ranking algorithm, handling different resume formats, managing vector embeddings, and optimizing performance using FAISS and Redis caching required significant experimentation and tuning.
